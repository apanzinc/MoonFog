# MoonFog 设置面板结构（结合项目介绍的整理版）

> 依据 `newtab.html` / `js/settings.js` / `js/config.js` + 项目介绍（[docs/project-overview.md](project-overview.md)）整理。
> 目标：**L1 一级 → L2 二级页（仅多子项时）→ 页内卡片/条件组**，命名全局统一。
> 状态：✅ **已实施**（2026-10-25）。代码与本文一致；单设置项页已按规则并入上级页，不再单独建页。

## 一、总体结构

```
L1（5 项，含副文本）      L2（二级页）                页内卡片
──────────────────────────────────────────────────────────────────────
外观与主题 ────┬─ 主题与背景 ─────────  明暗 / 背景来源 / [条件]模式参数 / 界面色调
（背景、明暗、 ├─ 问候区             预览 / 显示内容 / [条件]文案·时间·一言
 色调与问候字体）├─ 文字               问候主文案 / 副标题 / 搜索框 / 快捷标签
               └─ 显示与效果         常显按钮 / 模糊 / 性能
搜索联想 ──────────（单页双卡）          搜索引擎（引擎列表 / 添加自定义）
（引擎选择与输入建议）                  搜索建议（联想开关）
快捷导航 ─────┬─ 快捷方式            主页显示 / 主页入口 / 展开 / 编辑弹窗
（快捷方式、文└─ 导入与同步          HTML 导入 / 书签同步 / 安全说明
 件夹与书签同步）
数据与备份 ────────（单页双组）          备份与恢复（导出 JSON / 导入 JSON）
（导出导入与重置）                      重置（二次确认）
关于朔雾 ──────────（单页）              品牌横幅 / 开发 / 维护
（版本、开源许可与致谢）
```

### 与旧结构的关键差异（结合项目介绍修正）

| 旧结构 | 新结构 | 依据 |
|---|---|---|
| 「图片」二级单选 → 本地/在线 | 4 个并列背景模式：纯色 / 流光渐变 / 本地图片 / 必应每日壁纸 | `moonfog_bg_mode` = solid/grain/local/bing |
| 导航「收藏夹」 | 快捷导航 | 项目介绍称「快捷导航」，且含书签同步 |
| 导航「个性化」 | 外观与主题 | 与 OOBE 文案、页面标题统一 |
| 「字体」/「文字」混用 | 统一为「文字」 | 消除命名歧义 |
| 「展开行为」「重置」单独成页 | 并入上级页（快捷方式 / 数据与备份） | 规则：一页只有一个设置项时不单独建页 |

## 二、各页明细

### L1-1 外观与主题

#### ① 主题与背景（L2: appearance-bg）

```
卡片 A｜界面明暗
  浅色 / 深色 / 跟随系统（matchMedia 监听）
  tip：控件与面板的浅深模式

卡片 B｜背景来源（moonfog_bg_mode，4 单选）
  纯色 / 流光渐变 / 本地图片 / 必应每日壁纸
  ├─ [条件] 纯色 → 卡片 C
  ├─ [条件] 流光渐变 → 卡片 D
  ├─ [条件] 本地图片 → 卡片 E
  └─ [条件] 必应每日壁纸 → 卡片 F

卡片 C｜界面色调（仅纯色背景）
  7 预设色板：暖沙 #F5F0E8 / 奶油 #FDF6EC / 玫瑰 #F8EDE8 /
            青苔 #ECEEE5 / 晴空 #E8F0F5 / 薄紫 #EDE8F0 / 素墨 #E8E9EC
  + 自定义主题色（弹出全局取色器，存 moonfog_custom_color）
  tip：基于 Material You 从主题色生成整套色板

卡片 D｜流光渐变（仅流光渐变背景）
  形态：四角 / 波浪 / 点阵 / 嵌片 / 涟漪 / 团块 / 球体（WebGL 着色器）
  配色：
    「自动生成」tab — 主题色按钮 + 6 预设色（从主题色 HSL 派生 7 色）
    「自定义」tab — 2–7 个颜色槽 + 颜色数量分段（2/3/4默认/5/6/7）
  滑块（含默认值）：
    动画速度 0–150%（默认 66%）
    颗粒强度 0–100（默认 86）
    过渡柔和 0–100（默认 100）
    形变强度 0–100（默认 100）
  图案位置：水平 -100~+100（左↔右）/ 垂直 -100~+100（下↔上），默认 0
  「恢复默认」按钮

卡片 E｜本地图片（仅本地图片背景）
  「选择图片」/「清除」（带确认弹窗）
  tip：仅保存在本机，≤2.2MB 存 localStorage

卡片 F｜今日壁纸（仅必应每日壁纸）
  预览图 + Bing 来源标识 + 标题 + 版权
  「了解此图片」链接 + 「换一张」按钮（从 8 张本地池轮换）
  tip：8 张离线池，无网可用

卡片 G｜主题色（动态，图片类背景时）
  图片背景（本地 / 必应）自动从图片取主色调 → 生成 primary/secondary/accent
  失败回退 Material 紫
```

#### ② 问候区（L2: greeting）

```
卡片 A｜预览（实时预览卡：标题 + 副文案）

卡片 B｜显示内容（五态独立开关）
  问候语 / 自定义文本 / 当前时间 / 日期 / 每日一言

卡片 C｜文案 [条件：问候语 / 自定义文本]
  [问候语]  显示名称（≤20 字，占位「输入你的名字…」）
  [自定义文本] 自定义欢迎语（≤48 字，0/48 计数）

卡片 D｜时间选项 [条件：当前时间]
  小时制：24 时 / 12 时
  下方日期：显示 / 隐藏

卡片 E｜每日一言 [条件：每日一言]
  字数上限滑块 16–48 字（默认 32）
  tip：超限自动换句，最多尝试 10 次；API 挂时用本地 20 条兜底
```

#### ③ 文字（L2: type）

```
四张区卡片，每张均含「字体下拉（内置 思源宋体 / 系统默认 + 系统全部字体）」+「粗细滑块 400–700」：
  ① 问候主文案 — 字体 + 大小 70–140% + 粗细
  ② 来源副标题 — 字体 + 大小 70–140% + 粗细
  ③ 搜索框     — 字体 + 粗细（无大小，默认 400）
  ④ 快捷标签   — 字体 + 粗细（无大小，默认 500「中等」）
```

#### ④ 显示与效果（L2: display）

```
卡片 A｜常显设置按钮（默认开）
  tip：关闭后悬停右下角才出现

卡片 B｜模糊
  背景模糊 0–40px（默认 20）[条件：图片类背景]
  tip：部分档 ×0.45 上限 6px；限制档为 0
  背景压暗 -50（偏黑）~0~+50（偏白）（默认 -20）[条件：图片/流光]
  设置面板模糊 0–40px（默认 10，始终可用）

卡片 C｜性能（三档）
  完全（默认）/ 部分（模糊×0.45 上限 6px、关动画）/ 限制（关模糊与动画）
  动态 tip：显示当前档实际效果
```

## 六、迁移注意（已落实项存档）

1. **导航层**：`PERSONALIZATION_CHILDREN` 已改为 `SETTINGS_CHILDREN`；`navigateSettings` 按 `SETTINGS_CHILDREN` 判断深度（子页为三级，L1 直达页为二级）。
2. **标题**：`SETTINGS_PAGE_TITLES` 按第三节统一；返回键自动显示父级名。
3. **背景模式**：设置面板按 solid/grain/local/bing 4 个并列模式渲染，已删除旧「图片→本地/在线」子选择（`bgImageSubSelect`）。
4. **boot 链**：`boot-config.js` 注入的 CSS 变量（明暗两套、字体/字号/字重、性能档模糊折算）与设置项一一对应——改设置项后要核对注入逻辑；性能档折算（部分 ×0.45 上限 6px、限制 0）作为「显示与效果」动态 tip 呈现。
5. **条件组**：`hidden` + `settings-reveal` 机制保持，容器归到新页。
6. **OOBE 对齐**：文案已同步（kicker「外观与主题」+ 4 项卡片名与 L1 一致）。
7. **重置语义**：保持「清 moonfog_*、保留壁纸与一言缓存、清 OOBE 标记」，位于「数据与备份 → 重置」分组。
8. **导航动画**：L2↔L3 前进/返回滑动（`settingsSlideInLeft/Right` + 旧页 `settings-page-leaving` 视差滑出），`perf-balanced`/`low-perf` 档关闭页间动画。
