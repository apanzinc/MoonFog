## 性能

环境：本机 Playwright Chromium `158.0.8127.18`，1440 × 900，纯色背景、远程请求阻断。页面稳定 3.5 秒后取 2 秒样本；新版设置完成标记，比较相同主页。结果仅代表这个可复现的空闲场景。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 空闲 rAF 回调 / 秒 | 60 | 0 |
| 两秒内问候主文案 DOM 重写 | 2 | 0 |
| OOBE JS + CSS 原始字节 | 119,518 | 27,199 |
| OOBE JS + CSS gzip 字节 | 25,946 | 8,879 |

纯色不再返回空 `render`，流光帧由已有 ShaderMount 驱动，消除重复循环。时钟只显示时分，刷新改为分钟边界；后台停止定时刷新，回到前台立即同步，文字不变时不重写 DOM。本地图预览压缩后直接写入 IndexedDB，不再重复读取原文件和压缩。

没有生产环境的 Core Web Vitals / Lighthouse 数据，也没有把上述空闲计数换算成整站速度或电量提升。

## Edge 安卓

`npm run pack:edge-mobile` 生成专用 CRX / zip：保留 MV3 service worker 与 `search`，移除桌面专用 `fontSettings` 权限。扩展菜单图标可以在新标签页接管行为不同的宿主版本中直接打开 MoonFog，不增加 `tabs` 权限。

API 平台范围以 [Microsoft Edge 支持的 API](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/api-support) 为依据：`action`、`runtime`、`search`、`tabs` 支持 Android，`fontSettings` 仅列桌面平台。

自动化以 Pixel 7 尺寸、触控和 Edge 安卓 UA 跑界面；专用 zip 解包后还会实际加载进 Chromium 的扩展环境，验证 CSP、宿主检测、字体降级与设置入口。未连接 Android 真机；安装渠道、具体 Edge 版本与实体软键盘的设备差异仍需真机验证。Firefox 做打包结构校验，未宣称完成 Firefox 浏览器端到端测试。

## OOBE

重写为欢迎 → 背景 → 明暗 → 问候。预览和主页隔离，完成才保存；跳过保留当前配置。同步新壁纸库策略与旧背景键，避免选择只在当次生效。保存失败回滚部分偏好、保留草稿并允许重试；本地图必选有效图片。每日壁纸离线不会阻断流程。

使用原生 dialog 与显式 Tab 循环管理模态焦点。输入框使用原生编辑按键，步骤动画取消后同步渲染，不用延迟回调替换旧步骤。手机内容滚动、操作栏保留在视口，覆盖 320 × 568、844 × 390 和压缩到 360 × 360 的窗口。减少动效与性能档均生效，退出引导后恢复主页流光画布。

## PR #10 机器人反馈修复（2026-11-11）

复核 CodeRabbit 的 4 条行内反馈与 Verify 报告后补充以下修复：

- 壁纸 URL 比较统一经过浏览器 URL 解析，支持主机名大小写和相对地址；即时取色、延迟取色及异步完成检查使用相同规则，保留版本检查。
- 已处于本地图模式时，重新选择文件也会标记背景变更，保存后刷新可恢复新图。
- 原生 dialog 被系统意外关闭时解除主页隐藏；保存中关闭则等待结果，失败重新显示草稿并将焦点放到重试按钮。
- `3.14`、`1.2.3`、单整数或十六进制 IPv4 简写继续作为搜索词；完整四段 IPv4 和显式 HTTP(S) URL 保留导航能力。
- 新图片 / 视频加载失败或超时时保留当前背景，释放失败候选视频且不播放；首次加载没有可用背景时仍使用主题纯色兜底。
- OOBE 图片写入 IndexedDB 完成后才获取偏好快照；失败先恢复偏好，再只移除本次新增条目，不恢复整份壁纸库或源列表。

新增可控时序回归：在真实同源第二个标签页保存图片、源、主题和策略，暂停第一标签页的图片入库返回，再对完成标记注入一次失败，确认另一个标签页数据及 IndexedDB 图片保留、本次失败图片清理，随后重试成功。媒体测试使用虚拟时钟触发真实 9 秒超时分支；搜索测试验证请求取消后晚到结果不会重新显示。

当前本地结果：19 项单元测试通过；浏览器 60 项通过、2 项桌面触屏测试按设计跳过；静态检查、三类扩展打包、CRX3 头与 manifest 校验通过。浏览器范围仍为 Chromium 桌面及 Pixel 7 / Edge 安卓 UA 模拟，没有 Android 真机或 Firefox 浏览器验证。

将新增数字查询用例，以及本地图重选、跨标签页回滚、视频超时、URL 规范化四项浏览器用例回跑到原始 `7f478cc`：均按预期失败，确认覆盖了实际回归。

CF 网页预览：[moonfog-pr-10-preview.snesqwq.workers.dev](https://moonfog-pr-10-preview.snesqwq.workers.dev/)。部署来自 `npm run build:web` 的 `dist-web`，使用专用 Worker 的 Static Assets；更新代码后需重新构建并上传资源。该地址用于界面验证，Edge 安卓扩展安装仍需真机验证。

### 第二轮复审

补充处理复审行内反馈与 diff 外反馈：

- 壁纸渲染返回成功 / 失败，并仅允许当前请求发布加载错误。背景设置内明确标出加载失败的选择和仍在显示的背景，提供同一策略的重试按钮；成功重试或更换选择后清除旧错误。
- 再次打开引导时，从固定策略的图片条目恢复预览并复用原条目；未更换文件时不重复入库。读取已保存图片仍受会话及文件版本控制，缺失的 IndexedDB 图片不能作为有效选择继续。
- 为改动的保存、恢复、渲染与搜索函数补充职责及失败行为说明，响应函数文档覆盖率警告。

新增覆盖本地图不选新文件完成引导、切换背景后沿用旧图、保存图片缺失、设置内加载失败提示和成功重试。当前完整本地验证为 19 项单元测试、68 项浏览器测试通过，2 项桌面触屏专属测试跳过；三类扩展包及网页版构建通过。
